## 2024-06-02 - Authentication Form Accessibility & Submit Behavior
**Learning:** Found a recurring pattern in the application's authentication forms where inputs lacked `name` and `autocomplete` attributes, and primary action buttons were using `type="button"` instead of `type="submit"`. Relying solely on JavaScript to handle button clicks breaks native form submission behaviors, notably preventing users from submitting forms by simply pressing "Enter". Additionally, the lack of `name` and `autocomplete` attributes prevents password managers and browsers from correctly interpreting and autofilling form fields, which severely degrades the user experience and accessibility.
**Action:** When reviewing or creating forms, especially authentication forms, ensure all input fields have valid `name` and `autocomplete` attributes. Always use `type="submit"` for the primary submission button to natively enable 'Enter' key submissions. Ensure `onsubmit="event.preventDefault();"` is added if form submission logic is handled purely by JavaScript in static environments to prevent 501 Unsupported Method errors during local testing.
